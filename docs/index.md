# Tracker Blocker

Extensie de browser (Manifest V3, Chrome/Edge/Brave) care blocheaza pixeli de
tracking, curata parametri de tracking din URL-uri (fbclid, gclid, utm_* etc.),
detecteaza tracker-e deghizate prin CNAME cloaking, reduce fingerprinting-ul
si protejeaza impotriva scurgerilor de IP prin WebRTC.
